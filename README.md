## 🕹️ About the Game

Welcome to **Semester Survivor Simulator**, a lightweight browser game built in a single HTML file using vanilla JavaScript, HTML, and CSS. 

You start the semester with a balanced set of stats. Every choice you make throughout the game events will impact your resources. Study too hard, and your energy drops. Party too much, and your academics suffer. 

Can you make the right choices to reach the end of the semester successfully?

---

## ✨ Features

- 🔋 **Resource Management:** Balance four core stats:
  - **Energy** (Don't let it hit 0, or you collapse!)
  - **Academics** (Keep it high to pass your exams)
  - **Sports** (Stay healthy and active)
  - **Social** (Maintain your sanity and friendships)
- 📝 **Dynamic Events:** Encounter different scenarios (exams, parties, hackathons, rest days) that require tough choices.
- 🎨 **Retro Terminal UI:** A sleek, dark-mode terminal aesthetic with a classic typewriter text effect and ANSI-style colors.
- 📊 **Real-time Stat Tracking:** Visual progress bars that update instantly based on your decisions.
- 🏆 **Multiple Endings:** Your final evaluation depends on how well you balanced your stats by the end of the semester!

## 🛠️ Tech Stack

- **HTML5:** Game structure and UI layout.
- **CSS3:** Custom variables, flexbox styling, gradient stat bars, and retro animations (blinking cursor).
- **Vanilla JavaScript:** Game logic, state management, event sequencing, and DOM manipulation.

## 🧑‍💻 Local Development

Want to tweak the events or add your own scenarios?

1. Clone the repository:
   ```bash
   git clone https://github.com/Nimda6720/Semester_Survivor_Simulator.git
   ```
2. Open `index.html` in your favorite code editor.
3. Look for the `events` array in the JavaScript section to add or modify game scenarios!
4. Save and refresh the file in your browser to see your changes.
